🔐 Heimnetz-Zertifikat installieren

Damit gesperrte Seiten auch bei https:// sauber die Sperrseite zeigen statt einer Fehlermeldung, muss dieses Zertifikat einmal pro Gerät installiert werden.

Zertifikat herunterladen

Windows

  1. Datei Heimnetz-CA.crt doppelklicken → Zertifikat installieren
  2. Lokaler Computer → Weiter
  3. Alle Zertifikate in folgendem Speicher speichern → Vertrauenswürdige Stammzertifizierungsstellen
  4. Fertigstellen, Browser neu starten

Android

  1. Zertifikat herunterladen
  2. Einstellungen → Sicherheit → Weitere Sicherheitseinstellungen → Zertifikat installieren → CA-Zertifikat (je nach Hersteller etwas anders benannt; in den Einstellungen nach „Zertifikat“ suchen)
  3. „Trotzdem installieren“ bestätigen und die heruntergeladene Datei wählen

iPhone / iPad

  1. Diese Seite in Safari öffnen, Zertifikat herunterladen → „Zulassen“
  2. Einstellungen → Profil geladen → Installieren
  3. Einstellungen → Allgemein → Info → Zertifikatsvertrauenseinstellungen → „Heimnetz Sperrseite CA“ einschalten

macOS

  1. Datei doppelklicken → wird in der Schlüsselbundverwaltung geöffnet
  2. Zertifikat „Heimnetz Sperrseite CA“ doppelklicken → Vertrauen → Immer vertrauen

Firefox verwendet unter Windows und macOS standardmäßig das Systemzertifikat. Falls nicht: Firefox → Einstellungen → Datenschutz & Sicherheit → Zertifikate anzeigen → Zertifizierungsstellen → Importieren.
Das Zertifikat wird nur im Heimnetz verwendet und ausschließlich für die Sperrseite erzeugt.
